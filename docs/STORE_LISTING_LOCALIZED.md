# Korb — Localized Store Listing Copy

Translations of the listing fields in `STORE_LISTING.md` for the six languages
the app ships. Register these as **localizations** on the same App Store /
Google Play listing (App Store Connect → *Add Language*; Play Console → *Store
listing* → *Manage translations*), not as separate apps.

Character limits are the store's and apply per language — translations run
longer than English, so each field below is already trimmed to fit. Counts in
parentheses are the actual character length.

The non-listing sections of `STORE_LISTING.md` (privacy answers, data-safety
form, screenshot sizes, URLs) are language-independent — fill them in once.

Register the informal address in every language (du / tu / tú / ty), matching
the app's own voice.

## Before you publish

- Screenshots carry text from the app, so capture a set **per language** (or at
  least for the languages you promote most). Store listings with English
  screenshots under a translated description look unfinished.
- Keywords are per-language on Apple; the field is not shared across
  localizations, so each list above stands alone. Don't repeat words that
  already appear in the title — Apple indexes those anyway.
- Google Play generates its own machine translations if a language has no
  listing. Adding these replaces that with copy that matches the app's voice.
- These are AI-drafted. A native speaker read-through is cheap insurance
  before launch, especially for the title and subtitle, which you cannot
  change as freely later.
